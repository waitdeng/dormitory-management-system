# DMS V1.0 用户操作手册

> 面向：公司行政 / 人事 / 宿舍管理员 / 部门负责人  
> 系统：公司宿舍入住管理系统（DMS）V1.0

---

## 1. 登录与权限

1. 浏览器打开系统地址（如 `https://dms.example.com/`）。
2. 使用工号账号与密码登录。
3. 左侧菜单按角色显示；无权限的接口会返回 403。
4. **忘记密码**：联系系统管理员在「系统设置 → 用户管理」重置。
5. **部门负责人**：仅能看到授权部门范围内的员工、住宿、待办、报表数据。

### 角色一览

| 角色 | 典型权限 |
|---|---|
| 超级管理员 | 全部 |
| 人事 HR | 员工档案、导入导出、离职办理 |
| 行政/宿舍管理员 | 宿舍资源、分床、入住/调宿/退宿 |
| 部门负责人 | 本部门数据查看、报表导出 |
| 财务查看 | 报表查看/导出 |

---

## 2. 员工与部门

### 2.1 部门

- 菜单：员工管理 → 部门（或系统内部门页）
- 可创建、编辑部门；支持上下级树。
- 部门负责人字段用于自动纳入数据范围。

### 2.2 员工档案

- 列表支持：工号/姓名关键字、部门、人事状态、住宿状态筛选。
- 创建时**工号必填且唯一**。
- 详情页可查看当前住宿与住宿历史。

### 2.3 Excel 导入（历史数据迁移）

1. 下载模板：`GET /api/v1/employees/import/template` 或页面「下载模板」。
2. 填写数据（≤2000 行，≤5MB；日期 `YYYY-MM-DD`；**以工号匹配**）。
3. **预览**：系统校验并显示 新增 / 更新 / 错误 行数。
4. **确认提交**：写入数据库，生成错误明细。
5. 下载错误报告修正后可再次导入（已存在工号会走更新）。

注意：

- 重复工号、空工号、无效部门编码、非法日期会进入错误报告。
- 以 `=` `+` `-` `@` 开头的文本在导出时会做公式注入防护。

## 3. 宿舍资源

层级：区域 → 楼栋 → 楼层 → 房间 → 床位。

- 创建房间时可按容量自动生成床位（前缀默认 `B`）。
- 床位状态：
  - **空闲**：可分配
  - **已入住** / **已预留**：不可再分配
  - **维修**：已有住户可保留，不可新分配
  - **停用**：占用中不可停用；停用后不可分配

---

## 4. 入住与可视化分床

### 4.1 可视化分床（推荐）

1. 菜单：可视化分床。
2. 左侧展开宿舍树，点击**楼层**。
3. 「选择员工」→ 选择 `not_in_dorm` 员工。
4. 点击 **空闲** 床位 → 确认分床。
5. 系统完成：申请 → 批准 → 预留 → 确认入住。
6. 成功后床位变为 **已入住**，并自动刷新。

冲突提示：若他人已抢先占用，会提示「该床位已被其他管理员分配」并刷新。

### 4.2 传统入住单

菜单：入住管理 — 创建申请 → 批准 → 预留床位 → 确认入住。  
重复确认为幂等操作，不会重复建单。

---

## 5. 调宿

1. 菜单：调宿管理 → 新建（员工 + 目标床位 + 原因）。
2. 预留目标床位 → 确认调宿。
3. 原床位释放并结束旧记录（原因 `transfer`），历史保留。

约束：不可调到同一床位；目标床占用会 409 并回滚。

---

## 6. 退宿与离职

### 6.1 正常退宿

1. 菜单：退宿管理 → 创建退宿单。
2. 归还钥匙/门禁、清空物品、房间检查录入。
3. 确认退宿：住宿结束，床位释放。

### 6.2 离职联动

1. 人事将员工办理离职（`offboarding`）或办结（`terminated`）。
2. 系统生成**退宿待办**；**床位不会自动释放**。
3. 若离职后仍在住，会产生 **离职未退宿** 预警。
4. 行政按待办完成退宿后，床位释放、待办与预警关闭。

---

## 7. 待办与预警

- 待办中心：退宿待办、超期待办等；可标记完成/取消。
- 预警：离职未退宿、预留超期、停用仍占用、退宿超期等；可处理/解除。
- 预留超期由后台任务自动扫描（也可管理员手动触发）。

---

## 8. 报表与导出

| 报表 | 内容 |
|---|---|
| 住宿台账 | 当前有效住宿 |
| 空床统计 | 可分配床位 |
| 部门住宿 | 各部门在住/预留/人数 |
| 入退宿 | 历史入住/退宿事件 |
| 调宿 | 调宿记录 |
| 异常 | 待办/预警类异常 |

- 支持筛选与分页；「导出 Excel」遵循**相同数据范围**。
- 首页 Dashboard：空床、入住率、今日入退、离职未退宿、待办/预警等（员工类指标按数据范围过滤）。

---

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| 看不到某员工 | 是否在数据范围内；工号是否正确 |
| 空床数和别人不一样 | 点「刷新状态」；维修/预留床不计入可分配 |
| 分床提示 409 | 他人已分配；刷新后另选床位 |
| 导入报错 | 下载错误报告；检查工号/部门/日期 |
| 退出登录 | 顶栏头像 → 退出；令牌立即失效 |
