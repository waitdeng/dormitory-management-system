## 状态标记规则

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未开发 |
| 进行中 | 开发中 |
| 阻塞 | 有明确阻塞原因 |
| 已完成 | 开发+自检完成（含实际测试证据） |
| 已验收 | GPT Web 复核或最终验收确认 |

1. 只有实际完成并验证后才能标记「已完成」。
2. 不得将已完成阶段重置为未开始/待开发。
3. 状态变更写入本文件与计划/验收文档；不编造证据。
4. 自检结论 ≠ GPT Web 独立验收结论。
