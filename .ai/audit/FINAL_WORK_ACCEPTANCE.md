# ChatGPT Mac Work 最终验收任务模板

## 前提

- 用户已授权 Work 操作并且本地浏览器可打开测试环境；不可访问时不得假称已验证。
- 使用测试账户、合成数据、隔离 DB；严禁向正式数据执行写入。
- 在测试开始时记录版本 SHA、运行地址、浏览器/视口、数据集版本。

## 视觉巡检

- 逐页：1440x900 / 1024x768 / 项目支持时 390x844；截图留存。
- 检查导航、表格、弹窗、分页、长文案、布局溢出、滚动/焦点、键盘操作、颜色对比与状态反馈。

## 业务 E2E

- 从场景清单逐项执行：创建→查看→修改→流程状态变化→报表→导出。
- 检查无数据/校验错误/冲突/网络异常/刷新后持久性/多角色权限。
- 不能执行的场景列明具体阻塞和影响范围。

## 报告结构

1. 版本与环境
2. 完整场景矩阵（通过/失败/跳过/未测试）
3. UI/UX 问题与截图
4. 业务缺陷与复现步骤
5. 风险、阻断项、发布建议
6. 修复后复测记录

只读审查为默认；未经授权不修改代码、不开正式库写操作。
